# TZ-TV-WATCHER-PLUGIN

Technical specification (ТЗ) for the TV Watcher plugin for OpenClaw (MoltBot).

## Contents

- **[TZ.md](./TZ.md)** - full specification in Russian (21 sections, ~700 lines)

## Summary

Plugin for tracking TV series and movies, sending notifications about new episodes, date changes, and availability on streaming platforms. Natural language interaction, multiple data sources (TVMaze, TMDB, OMDb, Trakt), SQLite storage, SOLID architecture.
